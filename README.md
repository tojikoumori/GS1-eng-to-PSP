# Gyakuten Saiban / Ace Attorney 1 GBA - Case 4 ENG patch, full save, PSP XMB entry 
This was a project about Gyakuten Saiban / Ace Attorney 1 for GBA that releases: last case 4 english patch, a .sav with all cases unlocked, and a guide to make the game have its own XMB entry for PSP! (ICON0 and PIC1 included) 

You can now play this game fully in english, applying this and another patch made by h3rmit (all credits to them for that!), which translates the first 3 cases
